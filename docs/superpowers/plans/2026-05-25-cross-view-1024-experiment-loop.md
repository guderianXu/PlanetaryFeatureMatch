# Cross-View 1024 Experiment Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a repeatable 1024-cache training and evaluation loop that splits by source image, trains on Rotate/Viewpoint/Compound cache data, and reports six gate/style result groups with visual samples under `runs/`.

**Architecture:** Add small Python utilities around the existing PyTorch training and cache evaluator instead of rewriting training logic. Source-level split directories are built with symlinks so existing `pfm_pytorch_training.py` and `pytorch_cache_match_eval.py` continue to consume ordinary cache directories.

**Tech Stack:** Python 3.12, PyTorch, existing synthetic cache archives, unittest, pathlib, subprocess, matplotlib/OpenCV for visual outputs.
